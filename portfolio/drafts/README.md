# Hidden pages

These pages are hidden from the site while their content is being updated.
Files in this folder are not published.

To bring one back:
1. Move it back into `portfolio/pages/` (e.g. `drafts/about.js` → `pages/about.js`).
2. Add its link back to the menu in `portfolio/components/Header.js`, e.g.
   `<Link href="/about">About</Link>`
